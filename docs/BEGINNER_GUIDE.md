# 초보자 안내서

[README로 돌아가기](../README.md)

## 1. 설치하기

1. [최신 Release](https://github.com/obundh/gonggong-ax-local-4/releases/latest)를 엽니다.
2. `GonggongAX-Series4-Setup-x64-v4.1.0.exe`를 받습니다.
3. 설치 후 시작 메뉴의 `공공 AX 업무 매크로`를 엽니다.

처음 쓰는 분은 필요한 구성 요소를 자동으로 준비하는 Setup 설치파일을 권장합니다.
`GonggongAX-Series4-Portable-x64-v4.1.0.zip`을 사용하는 경우에는 Microsoft
Visual C++ 2015-2022 x64 Runtime을 먼저 설치한 뒤 ZIP 전체를 새 폴더에 압축
해제하고 `공공AX-업무매크로.exe`를 실행하세요. `Source code` ZIP은 설치 파일이
아닙니다.

현재 공개 EXE는 미서명이라 Windows SmartScreen이 나타날 수 있습니다. Setup은 화면
녹화용 Visual C++ Runtime이 없으면 Microsoft 공식 설치파일을 받아 자동 설치하며,
그때만 UAC가 나타날 수 있습니다.

## 2. 화면에서 볼 것

- 위쪽 `● 기록`, `■ 기록 끝`, `▶ 실행`, `■ 실행 중지`
- 왼쪽 녹화 영상과 이벤트 오버레이
- 오른쪽 현재 이벤트 목록
- 접혀 있는 `고급 편집 · 직접 추가 / 시간 수정`
- 아래쪽 저장 경로와 `Ctrl + Shift + F12` 안내

경량 화면에서는 과거 `기록 저장소` 탭을 제거했습니다. 녹화 파일과 이벤트 JSON은
계속 날짜별 폴더에 저장됩니다.

## 3. 메모장으로 바로 시험하기

이 순서는 실제 v4.1.0 검증에 사용한 방식입니다.

### 기록

1. 메모장을 열어 빈 문서를 준비합니다.
2. 앱에서 시작 지연을 `3초`로 둡니다.
3. `● 기록`을 누르고 메모장으로 이동합니다.
4. 아래 문자열을 그대로 입력합니다.

```text
z9final7
```

5. 앱으로 돌아와 `■ 기록 끝`을 누릅니다.
6. 오른쪽 이벤트 목록에 키 입력이 들어왔는지 확인합니다.

별도의 승인 창, `추가 확인`, 민감정보 의심 경고는 나타나지 않습니다. 필수 입력값이
없는 등 기술적으로 실행할 수 없는 이벤트만 `실패`로 표시됩니다.

### 실행

1. 메모장에서 새 빈 문서를 엽니다.
2. 앱에서 `▶ 실행`을 누릅니다.
3. 시작 지연 안에 빈 메모장으로 이동합니다.
4. `z9final7`이 다시 입력되는지 확인합니다.

녹화 시작 뒤 첫 키를 누르기 전까지 기다린 시간은 실행에서 제거됩니다. 따라서 시작
지연이 끝나면 첫 번째 실제 키가 바로 실행됩니다. 그 뒤 키 사이의 순서는 유지됩니다.

## 4. 그림판 드래그 시험하기

1. 그림판을 열고 빈 캔버스를 준비합니다.
2. 앱에서 `● 기록`을 누르고 그림판으로 이동합니다.
3. 캔버스에 서로 구분되는 선을 세 번 드래그해 그립니다.
4. 앱으로 돌아와 `■ 기록 끝`을 누릅니다.
5. 이벤트 목록에 세 개의 드래그가 기록됐는지 확인합니다.
6. 그림판 캔버스를 비우되 창 위치와 크기는 그대로 둡니다.
7. `▶ 실행`을 누르고 그림판으로 이동합니다.

세 번의 드래그 궤적이 다시 그려지면 정상입니다. 앱은 드래그 시작점만 클릭하는 것이
아니라 경로 지점과 각 지점의 상대 시간을 저장해 재생합니다. 영상 위에도 드래그
궤적이 선으로 표시됩니다.

## 5. 이벤트를 바꾸고 싶을 때

- 삭제: 이벤트의 `×` 또는 선택 후 `Delete`
- 순서 변경: 이벤트의 `↑`, `↓`
- 영상 이동: 이벤트 행 클릭
- 시간 수정·수동 추가: 아래 `고급 편집` 펼치기

고급 편집은 기본으로 접혀 있습니다. 단순 녹화와 실행에는 열 필요가 없습니다.

## 6. 실행 중지

실행 중 `Ctrl + Shift + F12`를 누르면 남은 이벤트 실행을 중지합니다. 화면의
`■ 실행 중지` 버튼도 같은 용도입니다. 드래그 재생 중 중지되거나 오류가 나도 앱은
누르고 있던 마우스 버튼을 해제합니다.

## 7. 저장 위치

기본 위치는 Windows `비디오` 폴더 아래입니다.

```text
공공AX 업무 매크로/
└─ 기록 저장소/
   └─ yyyy/yyyy-MM/yyyy-MM-dd/
      ├─ 업무시연_....mp4
      └─ 업무시연_....mp4.series4.json
```

MP4는 화면 영상이고 `.series4.json`은 이벤트 시간, 키, 클릭 좌표와 드래그 경로를
담습니다. 최근 프로젝트 경로는
`%LOCALAPPDATA%\공공AX 업무 매크로\last-project.json`에 저장됩니다.

## 8. 잘 안 될 때

### 다른 위치를 클릭하거나 그려요

이 앱은 절대 화면 좌표를 사용합니다. 녹화할 때와 실행할 때 대상 창의 위치와 크기,
화면 해상도와 배율을 같게 맞추세요.

### 관리자 프로그램에서 입력되지 않아요

일반 권한 앱은 Windows 정책상 관리자 권한 창에 입력하지 못할 수 있습니다. 대상 앱과
매크로 앱의 권한 수준이 다르면 맞춰서 다시 확인하세요.

### 영상이 열리지 않아요

Windows N/KN은 Media Feature Pack이 필요할 수 있습니다. 영상 문제와 별개로 이미
기록된 실행 가능 이벤트는 이벤트 목록에서 실행할 수 있습니다.

### ZIP형이 실행되지 않아요

ZIP 안의 EXE만 꺼내지 말고 전체를 압축 해제하세요. `uiohook.dll`,
`ScreenRecorderLib.dll`, `SharpHook.dll`이 EXE와 같은 배포 폴더에 있어야 합니다.

## 9. 개발자용 빌드

일반 사용자는 이 단계가 필요하지 않습니다.

```powershell
dotnet restore .\tests\Series4.Desktop.Tests\Series4.Desktop.Tests.csproj --locked-mode
dotnet build .\Series4.Desktop.csproj -c Release -p:Platform=x64 --no-restore
dotnet test .\tests\Series4.Desktop.Tests\Series4.Desktop.Tests.csproj -c Release -p:Platform=x64 --no-restore
```

구조는 [아키텍처 문서](ARCHITECTURE.md), 저장 데이터 범위는
[개인정보 및 보안 안내](PRIVACY_AND_SECURITY.md)를 참고하세요.
