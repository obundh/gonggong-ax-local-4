공공 AX 업무 매크로 v4.1.1 - 먼저 읽어 주세요
================================================

사용 순서
---------
1. "● 기록"을 누릅니다.
2. 대상 프로그램에서 평소 업무를 시연합니다.
3. "■ 기록 끝"을 누릅니다.
4. 대상 화면을 처음 상태로 준비하고 "▶ 실행"을 누릅니다.

앱 내부 승인 창이나 추가 확인 단계는 없습니다.
시작 지연 뒤 첫 실제 이벤트가 바로 실행되며 이후 간격은 녹화대로 유지됩니다.
실행 중지는 Ctrl + Shift + F12입니다.

빠른 시험
---------
- 메모장: z9final7을 기록하고 새 빈 문서에서 다시 실행
- 그림판: 선 세 개를 드래그해 기록하고 빈 캔버스에서 다시 실행

드래그는 시작점, 끝점과 중간 경로를 모두 저장해 재생합니다.
직접 추가와 시간 수정은 접힌 "고급 편집"을 펼치면 나타납니다.
날짜별 기록 저장소 탭은 경량 화면에서 숨겨져 있지만 파일 저장은 계속됩니다.

알아둘 점
---------
- 마우스는 절대 화면 좌표를 사용합니다. 창 위치와 크기를 녹화 때와 같게 두세요.
- 일반 권한 앱은 관리자 권한 프로그램을 조작하지 못할 수 있습니다.
- 공개 EXE는 미서명이라 Windows SmartScreen이 표시될 수 있습니다.
- 초보자는 필요한 구성 요소를 자동으로 준비하는 Setup 설치파일을 권장합니다.
- Setup은 Visual C++ Runtime이 없으면 Microsoft 공식 설치파일을 자동 실행하며,
  그때만 Windows UAC가 나타날 수 있습니다.
- Portable ZIP은 Microsoft Visual C++ 2015-2022 x64 Runtime이 미리 필요합니다.

영상과 이벤트 JSON은 Windows 비디오 폴더 아래
"공공AX 업무 매크로\기록 저장소"에 저장됩니다.

자세한 설명은 BEGINNER_GUIDE.md를 확인하세요.
