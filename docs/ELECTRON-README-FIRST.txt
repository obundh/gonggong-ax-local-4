공공 AX 로컬 시리즈 4 · v4.2.0

[실행]
설치판: 시작 메뉴의 '공공 AX 업무 매크로'
포터블: ZIP 전체 압축 해제 후 '공공AX-업무매크로.exe'
Electron과 .NET 런타임 포함. Node.js, npm, .NET SDK 설치 불필요.
포터블은 Microsoft Visual C++ x64 Runtime이 필요합니다.
설치판은 해당 Runtime이 없을 때만 공식 다운로드·설치를 진행합니다.
코드 서명 미적용으로 SmartScreen 안내가 나타날 수 있습니다.

[사용]
업무 보여주기 → 3초 후 평소처럼 작업 → Ctrl + Shift + F12 종료
영상·행동 로그 확인 → 필요 동작 수정 → 대상 창 준비 → 실행
스튜디오: 영상과 로그 나란히. 컴팩트: 작은 창. 같은 기록 공유.
반복 횟수: 1~999회 직접 설정
동작 사이 대기: 로그의 ＋ → 대기, 0.1~3600초 직접 설정
실행 중 긴급 정지: Ctrl + Shift + F12
동봉한 '소개 만화' 폴더에서 2장 소개를 볼 수 있습니다.

[주의]
영상 분석이나 AI 학습이 아니라 저장된 입력을 다시 실행합니다.
창 위치·크기·화면 배율·시작 화면·입력 언어를 시연 때와 맞추세요.
반복 사이 화면을 자동으로 초기화하지 않습니다. 먼저 1회 시험하세요.
녹화 중 CPU·GPU·디스크 사용이 늘어 PC가 느려질 수 있습니다.
암호·민감한 업무 입력을 기록하지 마세요.
Windows x64 주 모니터 대상. IME·관리자 권한 앱·다중 모니터는 별도 확인이 필요합니다.
