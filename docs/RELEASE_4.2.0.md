- Electron UI와 C# 녹화·재생 엔진 통합 배포
- 스튜디오·컴팩트 모드와 자동 창 크기 조절, 동일 작업 공유

- 영상 플레이어 옆 행동 로그, 영상 위 클릭 위치·동작 표시

- 소개 만화 2장 동봉

## 실행 환경

Windows x64. Electron·.NET 런타임 포함으로 Node.js·npm·.NET SDK 설치 불필요.
설치판은 Visual C++ x64 Runtime이 없을 때만 Microsoft 공식 파일을 받아 설치합니다.
포터블은 해당 Runtime을 미리 준비해야 합니다. 서명 미적용으로 SmartScreen이 표시될 수 있습니다.
기존 앱을 종료한 뒤 설치하세요. 비디오 폴더의 사용자 기록은 삭제하지 않습니다.

## 한계

영상 분석·AI 학습이 아니라 저장된 입력 재실행입니다.

녹화 중 PC 부하가 증가합니다. 민감한 업무 입력을 녹화하지 마세요.
