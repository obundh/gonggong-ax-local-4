## v4.1.0 경량판

처음 설치하는 분은 Assets에서 `GonggongAX-Series4-Setup-x64-v4.1.0.exe` 하나를
받으면 됩니다. 압축형은 `GonggongAX-Series4-Portable-x64-v4.1.0.zip`입니다.
GitHub가 자동으로 붙이는 `Source code` ZIP은 실행 프로그램이 아닙니다.

### 달라진 사용 흐름

- 기본 흐름을 `기록 → 업무 시연 → 기록 끝 → 실행` 네 단계로 단순화
- 앱 내부 승인 모달, `추가 확인`, 민감정보 의심 경고 UI 제거
- 필수 payload가 깨진 개별 이벤트만 실패 처리
- 날짜별 기록 저장소 탭과 도달 불가능한 관련 코드를 경량판에서 제거
- 직접 추가·시간 수정 UI를 접힌 `고급 편집`으로 이동
- 실행 때 첫 실제 이벤트 전의 빈 대기 시간을 제거하고 이후 간격은 유지
- 기록 끝에서 입력 훅 처리를 비운 뒤 저장해 마지막 키·클릭·드래그 유실 방지
- 입력 훅 준비를 확인한 뒤 녹화를 시작하고 빠른 입력은 순서 보존 큐로 처리

### 드래그 지원

- 마우스 드래그의 버튼, 시작·끝 좌표, 전체 시간과 중간 경로를 기록
- 저장한 상대 시간에 맞춰 전체 드래그 경로 재생
- 영상 위에 드래그 궤적 표시
- 취소나 오류가 발생해도 누른 마우스 버튼 해제
- 버튼 해제 실패 시 다음 이벤트를 실행하지 않고 즉시 중단
- 빠른 드래그도 release 좌표를 끝점으로 강제 저장
- 새 드래그 필드를 JSON에 저장하면서 기존 기록과 호환

### 실제 검증

- 메모장에서 마지막 키 직후 기록을 끝내도 `z9final7` 8글자를 모두 저장·재생
- 그림판에서 세 번의 드래그 기록 후 빈 캔버스에 세 획 재생
- 드래그 전체 경로 순서, 취소 시 버튼 해제, 해제 실패 중단 자동 테스트

### 알려진 한계

- 마우스는 절대 화면 좌표를 사용하므로 실행 전 창 위치, 해상도와 배율을 녹화 때와
  같게 맞춰야 합니다.
- 일반 권한 앱은 관리자 권한 창에 입력하지 못할 수 있습니다.
- OCR, 요소 탐색, 조건 대기와 분기는 아직 지원하지 않습니다.

### 설치 참고

Windows 10/11 x64용 self-contained 배포입니다. 공개 EXE는 아직 코드 서명 인증서로
서명되지 않아 SmartScreen이 표시될 수 있습니다. 화면 녹화용 Visual C++ Runtime이
없는 PC에서는 해당 Microsoft 런타임 설치 때 UAC가 나타날 수 있습니다.
