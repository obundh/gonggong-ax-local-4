# 초보자 안내서

[README로 돌아가기](../README.md)

이 문서는 처음으로 공공 AX 로컬 시리즈 4를 빌드하고, 테스트 녹화를 만든 뒤, 이벤트를 확인하고 실행하는 과정을 설명합니다.

## 1. 준비하기

필요한 환경은 다음과 같습니다.

- Windows 10 또는 Windows 11 x64
- .NET 10 SDK
- 키보드와 마우스를 직접 조작할 수 있는 테스트용 프로그램

처음에는 실제 업무 파일 대신 메모장과 복사본 문서를 사용하세요. 저장, 삭제, 전송처럼 결과를 되돌리기 어려운 동작은 테스트에서 제외하는 것이 좋습니다.

설치된 SDK를 확인합니다.

```powershell
dotnet --version
```

출력된 주 버전이 `10`이어야 합니다.

## 2. 빌드하고 실행하기

PowerShell에서 이 저장소 폴더로 이동한 뒤 실행합니다.

```powershell
dotnet restore .\Series4.Desktop.csproj --locked-mode
dotnet build .\Series4.Desktop.csproj -c Release -p:Platform=x64
dotnet run --project .\Series4.Desktop.csproj -c Debug -p:Platform=x64
```

이 저장소는 source-only로 공개됩니다. EXE나 설치 파일이 자동으로 제공된다고 가정하지 마세요.

## 3. 첫 화면 이해하기

화면은 크게 세 부분으로 나뉩니다.

- 왼쪽: 녹화 영상과 재생 조작
- 오른쪽 `현재 기록` 탭: 이벤트 타임라인과 수동 편집
- 오른쪽 `기록 저장소` 탭: 날짜별 과거 기록

화면 위쪽에는 녹화 시작·중지, 매크로 실행·중지 버튼과 시작 지연 시간이 있습니다.

## 4. 테스트 업무 녹화하기

1. 시작 지연 시간을 선택합니다. 처음에는 `3초` 이상을 권장합니다.
2. `화면 녹화 시작`을 누릅니다.
3. 지연 시간 동안 메모장 같은 대상 프로그램으로 이동합니다.
4. 테스트 문장을 입력하고, 클릭이나 휠을 몇 번 사용합니다.
5. 업무 시연이 끝나면 앱으로 돌아와 녹화를 중지합니다.
6. 영상 저장과 이벤트 정리가 끝날 때까지 기다립니다.

녹화 엔진이 실제 녹화 상태가 된 뒤부터 이벤트가 쌓입니다. 앱 자신의 버튼을 누른 동작은 업무 매크로로 다시 기록하지 않도록 제외됩니다.

현재 녹화 범위는 **주 모니터**입니다. 다른 모니터의 클릭이나 키 입력은 기대한 위치로 기록되지 않을 수 있습니다.

## 5. 영상과 이벤트 확인하기

왼쪽 플레이어에서 영상을 재생하면 해당 시간의 이벤트가 영상 위에 나타납니다.

- 마우스 이벤트: 녹화 당시 좌표 부근에 표시
- 키보드 또는 수동 이벤트: 화면 위 배너로 표시될 수 있음
- 추가 확인 이벤트: 주황색 경고와 이유가 보이지만 실행에는 포함됨
- 실행 불가 이벤트: 빨간색 표시와 기술적 제외 이유가 나타남

영상 속도 선택 상자에서 느리게 또는 빠르게 재생할 수 있습니다. 이 속도는 영상 검토용이며, 매크로 이벤트 시간 자체를 자동으로 다시 계산하지 않습니다.

## 6. 타임라인 편집하기

오른쪽 `현재 기록` 탭에서 할 수 있는 일은 다음과 같습니다.

### 이벤트 선택

목록에서 이벤트를 누르면 영상이 해당 시간으로 이동하고 아래 편집기에 내용과 시간이 표시됩니다. 경고는 실행을 막지 않으며, 실행 버튼을 누르면 경고 항목도 포함됩니다.

### 시간 수정

`시점(초)`에 `2.500`처럼 초 단위 값을 입력하고 `선택 수정`을 누릅니다. 영상 길이보다 뒤의 시간도 입력할 수 있으며 `영상 종료 후 실행` 경고가 표시됩니다.

### 순서 변경

이벤트 오른쪽의 위·아래 버튼을 사용합니다. 프로그램은 표시 순서와 실행 시간이 어긋나지 않도록 인접 이벤트의 시간 또는 같은 시간의 내부 순서를 함께 조정합니다.

### 삭제

개별 삭제 버튼이나 목록에서 `Delete` 키를 사용할 수 있습니다. `전체 삭제`는 현재 기록을 모두 비우므로 누르기 전에 프로젝트가 저장되었는지 확인하세요.

### 수동 이벤트 추가

동작 종류, 내용, 시점을 입력한 뒤 `새 로그 추가`를 누릅니다.

- 메모만 남기기: 영상에는 보이지만 실행하지 않음
- 텍스트 입력: 한글을 포함한 문자열을 현재 입력 위치에 입력
- 키 입력: `Ctrl+S`, `Enter`, `F5` 같은 키 또는 조합
- 왼쪽·오른쪽·가운데 클릭
- 위·아래·왼쪽·오른쪽 휠

수동 마우스 동작은 기록 좌표가 없으므로 실행 시점의 현재 커서 위치를 사용합니다.

## 7. 매크로 실행하기

실행 전에 다음을 확인하세요.

1. 녹화 때와 같은 주 모니터 위치와 해상도인지 확인합니다.
2. 대상 프로그램에서 테스트 파일을 엽니다.
3. 입력을 받을 창과 커서 위치를 준비합니다.
4. 시작 지연 시간을 선택합니다.
5. `매크로 실행`을 누릅니다.
6. 지연 시간 동안 대상 창으로 이동합니다.

키보드 입력이 포함되어 있는데 시작 지연 시간이 너무 짧으면, 프로그램이 대상 창을 선택할 시간을 확보하기 위해 지연을 둘 수 있습니다.

실행 중 문제가 생기면:

```text
Ctrl + Shift + F12
```

를 누르세요. 앱 창의 `매크로 중지` 버튼도 사용할 수 있습니다.

긴급 중지는 다음 이벤트 전송을 취소하기 위한 장치입니다. 이미 대상 프로그램이 처리한 저장·삭제·전송 결과를 되돌려 주지는 않습니다.

## 8. 날짜별 기록 불러오기

1. 오른쪽 `기록 저장소` 탭을 엽니다.
2. 필요하면 `새로고침`을 누릅니다.
3. 날짜 그룹에서 원하는 시간의 기록을 선택합니다.
4. 상태, 이벤트 수, 영상 존재 여부를 확인합니다.
5. `선택 기록 불러오기`를 누릅니다.

다른 기록으로 전환하기 전에 현재 편집 내용이 먼저 저장됩니다. 저장에 실패하면 전환을 중단하여 현재 내용을 보호합니다.

정상 완료되지 않은 녹화와 영상 파일이 없는 기록도 경고와 함께 이벤트를 실행할 수 있습니다. 영상 파일이 없으면 영상 재생과 오버레이 확인만 사용할 수 없고, 실행 가능한 이벤트 로그는 그대로 실행됩니다.

## 9. 파일은 어디에 저장되나요?

기본적으로 Windows의 `비디오` 폴더 아래에 저장됩니다.

```text
공공AX 업무 매크로/
└─ 기록 저장소/
   └─ 2026/
      └─ 2026-07/
         └─ 2026-07-31/
            ├─ 업무시연_....mp4
            └─ 업무시연_....mp4.series4.json
```

MP4는 화면 영상이고, `.series4.json`은 이벤트·시간·좌표·상태를 담은 sidecar 파일입니다. 두 파일을 다른 위치로 옮길 때는 함께 옮기세요.

최근에 연 프로젝트를 기억하는 작은 포인터 파일은 `%LOCALAPPDATA%\공공AX 업무 매크로\last-project.json`에 저장됩니다.

## 10. 개인정보와 보안

녹화를 시작하기 전에 다음을 확인하세요.

- 비밀번호, 주민등록번호, 계좌번호가 화면에 보이지 않는가?
- 알림 팝업이나 메신저가 녹화 화면에 나타날 가능성이 없는가?
- 입력 이벤트에 비밀 문구나 단축키가 포함되지 않는가?
- 생성된 MP4와 JSON 폴더의 Windows 접근 권한이 적절한가?

현재 버전은 수동 텍스트 이벤트의 전화번호·이메일·긴 숫자열·민감 키워드를 로컬 규칙으로 추정해 경고합니다. 이 경고는 실행을 막지 않으며 영상 마스킹이나 암호화 저장을 제공하지 않습니다.

## 11. 자주 생기는 문제

### 실행 버튼이 켜지지 않아요

- 녹화·마무리·다른 프로젝트 불러오기가 진행 중일 수 있습니다.
- 실행 가능한 이벤트가 없거나 모두 기술적 `실행 불가` 상태일 수 있습니다.
- 미완료 프로젝트나 영상 파일 누락은 경고로 표시되지만 실행 버튼 자체를 끄지는 않습니다.

### 좌표 이벤트에 화면 변화 경고가 보여요

녹화 당시와 현재 주 모니터의 위치 또는 해상도가 다르면 경고가 표시됩니다. 실행을 누르면 기존 절대 좌표로 계속 실행하며, Windows가 해당 좌표로 커서를 이동하지 못한 개별 이벤트만 건너뜁니다.

### 관리자 프로그램을 조작하지 못해요

Windows는 일반 권한 프로그램이 더 높은 권한의 창에 입력을 보내는 것을 제한할 수 있습니다. 권한을 무조건 높이기 전에 테스트 환경과 조직 보안 정책을 확인하세요.

### 드래그가 실행되지 않아요

현재 드래그 재생은 지원하지 않습니다. 드래그로 감지된 이벤트는 목록과 영상에 남고, 필요한 종료 좌표·지속시간 데이터가 부족한 `실행 불가` 항목으로 표시됩니다.

### 과거 기록에 영상 없음이 표시돼요

MP4와 `.series4.json`이 같은 폴더에 있는지 확인하세요. JSON만 복사했거나 MP4 이름을 바꾸면 연결이 끊길 수 있습니다.
