공공 AX 업무 매크로 - 먼저 읽어 주세요
=========================================

1. 설치형을 사용했다면 시작 메뉴에서 "공공 AX 업무 매크로"를 엽니다.
2. ZIP형은 이 폴더의 "공공AX-업무매크로.exe"를 실행합니다.
3. 별도의 .NET 설치나 SDK는 필요하지 않습니다.
4. 처음에는 메모장을 대상으로 3초 지연을 두고 짧게 시험하세요.
5. 실행 중에는 Ctrl + Shift + F12로 즉시 중지할 수 있습니다.

설치형은 Microsoft Visual C++ x64 Runtime이 없는 경우 Microsoft 공식 서버에서
받아 설치합니다. 이 선행 구성요소 설치에 한해서 관리자 승인이 필요할 수 있습니다.
ZIP형은 해당 런타임이 이미 설치된 PC용입니다. Windows N/KN은 Media Feature
Pack을 별도로 켜야 화면 녹화가 작동합니다.

이 프로그램은 화면 의미를 이해하지 않고 녹화한 절대 좌표와 키 입력을
다시 실행합니다. 경고는 실행을 막지 않지만, 현재 화면과 대상 파일은 직접
확인해야 합니다.

현재 공개 설치 파일은 코드 서명 인증서로 서명하지 않았습니다. 반드시
https://github.com/obundh/gonggong-ax-local-4/releases 에서 받은 파일인지와
Release의 SHA256SUMS.txt를 확인하세요.

자세한 단계는 BEGINNER_GUIDE.md를 확인하세요.
