# 개인정보 및 보안 안내

이 문서는 앱이 실제로 기록하는 데이터와 Windows 권한 경계를 짧게 설명합니다.

## 로컬에 저장되는 데이터

기본 저장 위치는 다음과 같습니다.

```text
%USERPROFILE%\Videos\공공AX 업무 매크로\기록 저장소\
  yyyy\yyyy-MM\yyyy-MM-dd\
    업무시연_....mp4
    업무시연_....mp4.series4.json
```

`Videos` 폴더를 사용할 수 없으면 `%LOCALAPPDATA%\공공AX 업무 매크로` 아래를
사용합니다. 최근 프로젝트 경로는 다음 파일에 저장됩니다.

```text
%LOCALAPPDATA%\공공AX 업무 매크로\last-project.json
```

MP4에는 주 모니터 화면이 들어갑니다. JSON에는 다음 정보가 들어갈 수 있습니다.

- 이벤트 종류, 시점과 순서
- 키 코드, 보조 키와 수동 텍스트 문자열
- 클릭·휠 좌표와 값
- 드래그 버튼, 시작·끝 좌표, 경로 지점과 상대 시간
- 녹화 당시 화면 영역

앱은 이 파일을 원격 서버에 업로드하지 않으며 애플리케이션 텔레메트리도 보내지
않습니다. 다만 `Videos` 폴더가 OneDrive나 조직 동기화 경로라면 해당 프로그램의
정책에 따라 파일이 동기화될 수 있습니다.

## 자동 검사나 승인 단계

v4.1.1 기본 UI에는 실행 전 승인 모달, `추가 확인`, 민감정보 의심 경고가 없습니다.
사용자가 기록과 실행을 누르면 그대로 진행합니다.

앱은 비밀번호 입력란, 개인정보, 업무 비밀을 자동으로 구분하거나 영상에서
마스킹하지 않습니다. 저장 파일도 앱 자체 암호화를 적용하지 않습니다. 녹화 파일을
공유할 때는 MP4와 JSON에 화면과 입력 정보가 함께 들어 있다는 점만 확인하면 됩니다.

이벤트 행을 삭제해도 이미 녹화된 MP4 화면은 바뀌지 않습니다.

## 실행 실패로 처리하는 경우

보안 판단으로 동작을 막지는 않습니다. 다음처럼 엔진이 재생할 필수 데이터가 없는
개별 이벤트만 실패 또는 건너뜀으로 표시합니다.

- 빈 텍스트나 키 payload
- X 또는 Y 한쪽만 있는 좌표
- 값이 0인 휠 이벤트
- 버튼 또는 경로가 없는 드래그
- 긴급 중지 단축키 자체

정상 클릭, 키, 휠과 완전한 드래그 경로는 별도 승인 없이 실행 목록에 포함됩니다.

## 절대좌표 방식

마우스 동작은 녹화 당시 절대 화면 좌표를 사용합니다. 실행할 때 창 위치, 화면
해상도나 배율이 달라지면 다른 곳을 누르거나 그릴 수 있습니다. 앱은 UI 요소의 이름이나
의미를 다시 찾지 않습니다.

## Windows 권한과 UAC

앱은 기본적으로 일반 사용자 권한으로 실행됩니다. 대상 프로그램이 관리자 권한이면
Windows가 일반 권한 앱의 입력을 차단할 수 있습니다.

설치 파일은 현재 사용자 영역에 설치됩니다. 화면 녹화용 Visual C++ Runtime이 없는
PC에서는 Microsoft 런타임 설치 과정에서 UAC가 나타날 수 있습니다. 공개 EXE가
미서명인 동안에는 SmartScreen도 표시될 수 있습니다. 두 창은 앱 내부 승인 절차가
아니라 Windows가 표시하는 창입니다.

## 긴급 중지

```text
Ctrl + Shift + F12
```

녹화·실행 카운트다운과 진행 중인 녹화·실행을 중지합니다. 전역 단축키 등록이 안 되면
화면의 `실행 중지` 버튼을 사용할 수 있습니다. 드래그가 취소되면 재생 엔진은 누르고
있던 마우스 버튼을 해제합니다.

이미 대상 프로그램이 처리한 클릭이나 입력 결과를 되돌리는 기능은 아닙니다.

## 네트워크가 사용되는 때

앱 실행 자체에는 원격 API가 필요하지 않습니다. 다음은 앱 데이터 업로드와 별개입니다.

- 설치 중 필요할 수 있는 Microsoft Visual C++ Runtime 다운로드
- 소스 빌드 중 NuGet 패키지 복원
- Windows, 백신, EDR과 동기화 프로그램의 자체 통신
